# Local font assets

The existing Outfit and Onest variable families are self-hosted using `next/font/local` so builds do not depend on Google Fonts connectivity. The font variables and weight range are retained.

Downloaded unmodified on 2026-10-22 from the official Google Fonts repository:

- [Outfit source and license](https://github.com/google/fonts/tree/main/ofl/outfit), `Outfit[wght].ttf`, SHA-256 `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade`.
- [Onest source and license](https://github.com/google/fonts/tree/main/ofl/onest), `Onest[wght].ttf`, SHA-256 `966c5c29b4755da84b6854d5c21dd4eaa2420225d0e9874de602de176d4a9f31`.

The accompanying `Outfit-OFL.txt` and `Onest-OFL.txt` contain the respective copyright notices and SIL Open Font License terms. Keep them with the assets when redistributing. No font substitution, subsetting, or renamed font family is involved.
